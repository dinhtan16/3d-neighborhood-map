# 3D asset guidelines

Every model placed on the map must follow this contract. The procedural models in
`assets/models/` (generated by `pnpm assets:build`) follow it, so any of them can be
replaced by a hand-made Blender export with the same `asset_key` without code changes.

## Contract

| Property | Rule |
|---|---|
| Format | glTF 2.0 binary (`.glb`) |
| Units | 1 unit = 1 meter, real-world scale |
| Origin | **Base centre**: bounding box centred on X and Z, lowest point at Y = 0 |
| Up axis | +Y |
| Forward | **+Z** – shop fronts, signs, awnings, vehicle noses face +Z |
| Materials | Flat / toon look: base colour only, roughness 1, metallic 0. No PBR textures by default; small hand-painted atlases are OK |
| Budget | ≤ 3 k triangles for props, ≤ 5 k for buildings; ≤ 100 KB per GLB after compression |
| Compression | `EXT_meshopt_compression` (+ `KHR_mesh_quantization`). The web loader (drei `useGLTF`) decodes meshopt automatically |
| Naming | Meaningful node names (`Awning`, `Sign`, `Shopfront`, `RoofTank` …) |
| License | Must be recorded in `metadata.license`; only CC0 / owned / properly licensed content |

### Placement and rotation

A `map_objects` row stores `position` (lat/lng), `elevation_m`, `rotation`, `scale`.
The frontend computes:

```text
world position = projector.toLocal(lng, lat) → (x, elevation, z)
rotation.y     = rotation (radians, counter-clockwise seen from above)
rotation = 0   → model +Z faces world +Z = south
rotation = π   → faces north;  π/2 → faces east;  3π/2 → faces west
```

The importer sets `rotation = atan2(-ux, uy)` where `(ux, uy)` is the east/north unit
vector from the nearest road to the place, so the front faces the road.

### Manifest

`assets/models/manifest.json` lists every model with `assetKey`, `name`, `category`,
`file`, `boundingBox { min, max, size, origin, forward, units }` and `metadata`
(compression, triangle count, bytes, nodes, license, author). `pnpm db:seed` upserts
it into `map_assets`; bump `version` when replacing a model so caches are invalidated.

## Replacing a model with a Blender export

1. Model at real scale (Scene Properties → Units: Metric, scale 1.0).
2. Put the object's origin at the **centre of its base** (Object → Set Origin; snap
   the 3D cursor to the footprint centre at ground level).
3. Make the front face **-Y in Blender**. Blender is Z-up; the glTF exporter converts
   -Y (Blender) to +Z (glTF), which is the map's forward axis.
4. Apply all transforms (Ctrl+A → All Transforms) so the node has identity rotation/scale.
5. Use simple Principled BSDF materials with Base Color only (roughness 1, metallic 0),
   or one small texture atlas.
6. Export: File → Export → glTF 2.0, Format **glTF Binary (.glb)**, Include: Selected
   Objects, Transform: **+Y Up** ✔, Geometry: Apply Modifiers ✔, Normals ✔,
   UVs only if textured, no cameras / lights / animation.
7. Compress and check:

   ```bash
   npx @gltf-transform/cli meshopt input.glb assets/models/shophouse-01.glb
   npx @gltf-transform/cli inspect assets/models/shophouse-01.glb
   ```

8. Update the entry in `assets/models/manifest.json` (bounding box from `inspect`,
   license, author), bump `version`, and run `pnpm db:seed`.
9. Check it in the admin map editor: it should sit on the ground and its front should
   face the street at `rotation` values set by the importer.
